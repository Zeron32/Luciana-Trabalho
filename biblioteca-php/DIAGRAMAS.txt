  FLUXO DE EMPRÉSTIMO
═══════════════════════════════════════════════════════════════════════════

  Registrar Empréstimo:
  ────────────────────

    [Usuário seleciona livro e leitor]
              │
              ▼
    ┌──────────────────────┐
    │ Verificar se livro   │
    │ está disponível      │
    └──────┬───────────────┘
           │
           ▼ [Disponível]
    ┌──────────────────────┐
    │ BEGIN TRANSACTION    │
    └──────┬───────────────┘
           │
           ├─► Inserir registro em emprestimos
           │   (status = 'ativo')
           │
           ├─► Decrementar quantidade_disponivel
           │   no livro
           │
           ▼
    ┌──────────────────────┐
    │ COMMIT               │
    └──────────────────────┘


  Registrar Devolução:
  ───────────────────

    [Usuário clica em "Devolver"]
              │
              ▼
    ┌──────────────────────┐
    │ Calcular dias de     │
    │ atraso               │
    └──────┬───────────────┘
           │
           ▼
    ┌──────────────────────┐
    │ BEGIN TRANSACTION    │
    └──────┬───────────────┘
           │
           ├─► Atualizar emprestimos
           │   (data_devolucao = hoje, status = 'devolvido')
           │
           ├─► Incrementar quantidade_disponivel
           │   no livro
           │
           ▼
    ┌──────────────────────┐
    │ COMMIT               │
    └──────────────────────┘
